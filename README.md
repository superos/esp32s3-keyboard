ALL USAGES IN `config.h`

Hardware
- 1 x ESP32-S3 DevKit
- 1 x Si24R1 DevKit (PA+LNA)
- 1 x RGBCK Switch (Co-Anode)
- 1 x 6000mAh Battery (906090)
- wires, resistors(5k,10k,100k), capacitors(47uf,100uf)

Respect to
- USB supported by https://components.espressif.com/components/espressif/usb_host_hid
- BLE supported by https://github.com/h2zero/NimBLE-Arduino
- NRF supported by https://github.com/nRF24/RF24

And
- Arduino Community Edition : https://github.com/vscode-arduino/vscode-arduino
